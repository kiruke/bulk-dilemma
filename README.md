MEAT BULK
落ちてくる肉を選んでキャッチし、筋肉を育てながら体脂肪を管理する、ブラウザ向け2Dアクションゲーム（企画・開発予定）。
コンセプト
画面下の男性キャラクターを左右に動かし、上から落ちてくる肉を拾う。肉にはタンパク質と脂質のパラメータがあり、取得すると筋肉量と体脂肪率が変化する。筋肉が増減すると腕・肩・胸・脚の太さが、体脂肪率が変わると腹部・腰・顔の形が変化する。

肉を大量に拾うだけではなく、現在の身体の状態を見ながら「拾う／見送る」を判断するゲームを目指す。
MVP仕様（暫定）
- プレイヤー：男性キャラクター1人。女性キャラクターは将来の拡張候補。
- 操作：左右矢印キーまたは A / D キー。ジャンプなし。
- ゲーム時間：60秒（仮）。
- 肉：画面上部からランダムな位置に落下し、接触すると取得。地面に落ちた肉は消える。
- HUD：画面上部に「筋肉量」「残り時間」「体脂肪率」を常時表示。
- 肉を取ると栄養パラメータが反映され、筋肉量・体脂肪率・キャラクターの見た目が更新される。
- エネルギー不足が続くと餓死によるゲームオーバー。60秒生存すると結果画面へ。
- バックエンド・ユーザー登録・データベースは使用しない。
肉の種類（仮パラメータ）
肉	タンパク質	脂質
鶏むね肉（皮なし）	23	2
鶏もも肉（皮なし）	19	5
牛もも肉（赤身）	21	6
豚バラ肉	14	35


数値は100gあたりのおおよその栄養成分を参考にしたゲーム用の仮値。肉の状態や部位により実際の値は異なる。ゲーム内での増減量・出現率はプレイテストで調整する。
体型表現・ビジュアル
- キャラクター：2Dイラスト。リアルな筋肉の増減が分かる、ややデフォルメされた男性。
- 筋肉量：肩・上腕・胸・脚などの形状に反映。増えるだけでなく減る表現も必須。
- 体脂肪率：腹部・腰回り・顔などの形状に反映。
- 筋肉量と体脂肪率は独立したパラメータとして扱い、細身／筋肉質／脂肪が多い／筋肉も脂肪も多い体型を表現する。
- 単純なキャラクター全体の拡大縮小は避け、2Dパーツの変形や複数形状間の補間を検討する。
- 肉：実写に近いリアルな画像。背景透過のPNGまたはWebP素材を想定。
- 3Dモデルは使用しない。
ゲームバランスの方向性（未確定）
- 時間経過でエネルギーを消費し、肉を取らないリスクを設ける。
- 脂質は多すぎると不利だが、少なすぎてもエネルギー不足になる。
- 鶏むね肉だけを拾えば最適解になる設計を避ける。
- 「摂取脂質」「蓄積脂肪／体脂肪率」「エネルギー」は内部的に分けて管理する方向で検討する。
- 体脂肪率が高い場合の移動速度低下、筋肉量の減少、餓死条件、スコア計算は要調整。
- 現実の人体を正確にシミュレートするのではなく、分かりやすいゲームルールを優先する。

開発ステップ
1. 仮素材でキャラクターの左右移動を実装する。
2. 4種類の肉を落下させ、取得判定を実装する。
3. 筋肉量・体脂肪率・エネルギーのゲームロジックを試作する。
4. HUDを実装する。
5. 2Dキャラクターの筋肉・脂肪の増減表現を検証する。
6. 餓死・タイマー・結果画面を実装する。
7. 肉のリアル画像やキャラクター素材を整え、ゲームバランスを調整する。
